# Фича 003: Telegram-бот AO3Time

## Статус
В работе

## Ветка
feature/telegram-bot

## Vision (от пользователя)
Сделать телеграм-бота из текущего инструмента. Должен принимать ссылки на AO3, формировать PDF (по отдельности или ZIP), при желании собирать таблицу метаданных.

## Цель
Переиспользовать логику из src/core/, добавить бота на aiogram 3.x.

## Решения
- Фреймворк: aiogram 3.x
- Режим запуска: polling (локально)
- Доступ: только по user_id
- Десктоп-приложение остаётся
- Обе функции (PDF/ZIP и таблица метаданных) в одном боте
- Перед обработкой спрашивать: формировать ли таблицу метаданных?

## Структура
- src/bot/config.py - токен, разрешённые user_id
- src/bot/keyboards.py - клавиатуры
- src/bot/states.py - FSM состояния
- src/bot/handlers.py - обработчики
- src/bot/main.py - запуск бота

## Зависимости
- aiogram>=3.20.0
