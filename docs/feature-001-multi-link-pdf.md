# Фича 001: Мультиссылки AO3 -> PDF

## Статус
В работе

## Ветка
feature/multi-link-pdf

## Vision (от пользователя)
Нужно отправлять несколько ссылок на AO3 разом и получать по ним PDF-файлы для скачивания. Похоже на fichub.net, но с возможностью загрузить много ссылок сразу и получить выгрузку по всем.

## Цель
Сделать инструмент, который принимает список ссылок на произведения AO3 и формирует PDF для каждого (или пакет) для скачивания.
